# Mori — Монгольское письмо

Вертикальный текстовый редактор для традиционного монгольского письма (предварительная версия для macOS).

Традиционное монгольское письмо идёт **сверху вниз, столбцы — слева направо**. Поэтому интерфейс
горизонтальный: лист разворачивается в ширину, а текст растёт по вертикали.

![Mori на macOS](docs/preview.png)

> **Статус: рабочий предварительный выпуск (v0.2.0).**
> Редактирование, системные шрифты, сохранение исходного текста и явное преобразование кодировок
> уже работают. Однако проект **не прошёл** полную проверку соответствия китайским национальным
> стандартам для монгольского письма, и **ни один** корпоративный метод ввода не проверен на
> реальном устройстве. Не считайте это готовой заменой Word.

## Что это

Полностью автономное локальное приложение для Mac. Без доступа к сети, без загрузки документов,
без облачных сервисов, без встроенных коммерческих шрифтов и методов ввода.

- **Нативная оболочка**: Swift + AppKit + WKWebView, универсальный бинарник (Apple Silicon / Intel)
- **Редактор**: ProseMirror, `writing-mode: vertical-lr` — настоящая вертикальная вёрстка, а не повёрнутая горизонтальная
- **Преобразование**: Satsrag/mongol-convert 0.7.1 WASM, работает локально
- **Резервный шрифт**: Noto Sans Mongolian (SIL OFL 1.1)

## Что реализовано

### Редактирование и вёрстка
- Вертикальный форматированный текст: сверху → вниз, столбцы слева → направо; непрерывное горизонтальное полотно с масштабированием
- Заголовки / основной текст / списки; полужирный, курсив, подчёркивание, цвет текста
- Отмена / повтор, поиск и замена всех вхождений
- Шрифт, размер, межстрочный интервал, выравнивание, поля и направляющие на уровне документа
- Палитра управляющих символов: FVS (U+180B–180D), MVS (U+180E), NNBSP (U+202F), ZWJ / ZWNJ, монгольская пунктуация
- Показ кодовых точек выделения в реальном времени (U+XXXX), подсчёт символов, слов и символов области PUA

### Возможности macOS
- Строка меню AppKit, нативные панели открытия и сохранения, предупреждение о несохранённых изменениях при выходе
- **Перечисляет все установленные шрифты** и проверяет покрытие монгольских кодовых точек — установленные монгольские шрифты можно выбирать напрямую
- Подключается к жизненному циклу набора системного метода ввода и **никогда не изменяет документ во время набора**
- Сохраняет документы в `.mglx` с сохранением форматирования, настроек шрифта и исходных импортированных байтов
- Экспорт в TXT / HTML, системная печать и сохранение в PDF

## Что реально поддерживают три профиля кодировок

Три варианта с исходного скриншота соответствуют разным **соглашениям о глифах и управляющих
символах** — это не номера версий Unicode:

| Профиль | Поведение в этой версии | Ещё не сделано |
| --- | --- | --- |
| Монгольское письмо (нац. стандарт 2023) | Редактирование исходного Unicode, сохранение FVS / MVS, формирование выбранным шрифтом | Полное соответствие GB/T 25914-2023 |
| Монгольское письмо (нац. стандарт 2010) | Старые соглашения сохраняются дословно; буквы, селекторы вариантов и разделители суффиксов не переписываются | Автоматический переход 2010 ↔ 2023 |
| Монгольское письмо (кодировка Menksoft) | Редактирование текста в области PUA; предпросмотр преобразования MenkShape / MenkLetter и экспорт копии | Полные таблицы соответствия PUA-шрифтов, гарантия обратимости без потерь |

**Переключение профиля меняет только метаданные документа и никогда не переписывает кодовые точки
текста.** Это сделано намеренно: автоматический переход не проверен, а молчаливое преобразование
портит текст.

О названиях `International 2010` / `International 2023`: скорее всего, речь о соглашениях о глифах
стандартов GB/T 25914-2010 и GB/T 25914-2023 (редакция 2023 года заменила редакцию 2010 года), а
не о версиях Unicode. Как именно это реализовано у конкретного производителя, проект не проверял.

### Место GB18030

GB18030 — это **уровень байтовой кодировки файла**. Это отдельный вопрос от номинальных символов
монгольского письма, соглашений о глифах и формирования шрифта. При импорте используется системный
декодер; экспортируемый текст всегда в UTF-8.

## Безопасность преобразования

Измеренный результат: после кругового преобразования через текущий движок с открытым исходным кодом
образец слова `ᠮᠣᠩᠭᠣᠯ` возвращается **с другими номинальными буквами**. Поэтому:

- Преобразование **создаёт только предпросмотр и копию** — оно никогда не заменяет тело документа
- Каждое преобразование автоматически проверяется на обратимость и явно предупреждает при неудаче
- Отсутствие предупреждений движка и визуальное сходство глифов не доказывают отсутствие потерь

> Преобразование монгольских кодировок неизбежно теряет информацию из-за нормализации глифов.
> **Никогда не перезаписывайте единственный оригинал результатом преобразования.**

## Сборка

Требуются macOS, Apple Command Line Tools и Node.js 22+.

```bash
npm install
npm run build:web        # создаёт каталог web/ (в .gitignore)
```

Скрипт сборки нативного приложения по умолчанию пишет в `outputs/` рядом с каталогом проекта:

```bash
mkdir -p ../outputs
npm run build:mac        # компилирует arm64 + x86_64 и упаковывает ../outputs/Mori.app
```

Тесты:

```bash
npm test                 # 21 тест кодировок и целостности документов
```

Необязательная самопроверка нативного интерфейса (пишет отчёт и снимок экрана):

```bash
../outputs/Mori.app/Contents/MacOS/Mori \
  --smoke-test tests/native-results.json \
  --snapshot docs/preview.png
```

### Добавлено в v0.2

- **Шрифт и размер на уровне выделения** — элементы управления шрифтом и размером теперь меняют выделенный текст; без выделения меняется значение по умолчанию для документа.
- **Форматирование абзаца и символов** — заголовки H1–H3 (⌘0–⌘3), отступ абзаца, отступ первой строки, межстрочный интервал абзаца, четыре выравнивания, верхний и нижний индекс.
- **Параметры страницы и разбиение на страницы** — A4/A3, альбомная/книжная, поля, предпросмотр разбиения и PDF с разбиением. Разбиение вычисляется измерением каждого блока, поэтому заголовки занимают пропорционально больше места.
- **Импорт и экспорт DOCX** через локально установленный LibreOffice, запускаемый **отдельным процессом**. Ничего не линкуется и не поставляется в составе, поэтому обязательства GPL-3.0 не распространяются на этот проект под MIT. Путь задаётся через `MORI_SOFFICE`.

## Известные ограничения

- **Методы ввода**: подключение к стандартному набору реализовано, но Menksoft и различные
  корпоративные монгольские методы ввода всё ещё требуют проверки на реальном устройстве для
  каждого производителя и версии. Методы ввода Windows не начнут работать на macOS только потому,
  что добавлен адаптер кодировки.
- **Возможности Word**: нет таблиц, изображений, колонтитулов, нумерации страниц, сносок, режима правок и комментариев; разбиение на страницы — только предпросмотр, а не правка прямо на странице.
- **Разбиение на страницы и PDF**: реализованы разбиение с измерением каждого блока и вывод PDF с разбиением. Абзац длиннее страницы не разрывается — он занимает отдельную страницу с предупреждением об обрезке. Поглифовая точность PDF по-прежнему не проверена.
- **Диапазон письменностей**: полное преобразование для тодо, сибо и маньчжурского вне проверенного диапазона.
- **Резервная копия**: хранится только последняя рабочая область
  (`~/Library/Application Support/Mori/draft.mglx`), это не история версий.
- **Проверка платформ**: протестировано только на Apple Silicon; Intel и старые версии macOS не проверялись.
- **Подпись**: локальная временная подпись, **без подписи Apple Developer ID и без нотаризации**,
  поэтому при первом запуске на другом Mac может появиться предупреждение безопасности.


### Нормативные источники

- [GB/T 25914-2023](https://std.samr.gov.cn/gb/search/gbDetailed?id=0B4529DE108FFCAFE06397BE0A0A46CC) — номинальные символы, формы представления и правила использования управляющих символов для традиционного монгольского письма; заменяет редакцию 2010 года
- [Описание области PUA в Unicode](https://www.unicode.org/faq/private_use.html)
- [Unicode Standard §13.5](https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-13/) — монгольское письмо, включая эволюцию U+180E и U+202F
