## Энэ юу вэ

Бүрэн офлайн, локал Mac програм. Сүлжээнд холбогдохгүй, баримт байршуулахгүй, үүлэн үйлчилгээ
ашиглахгүй, худалдааны фонт, гарын оролтын аргыг хамт багцлахгүй.

- **Натив бүрхүүл**: Swift + AppKit + WKWebView, Universal бинар (Apple Silicon / Intel)
- **Засварлагч**: ProseMirror, `writing-mode: vertical-lr` — эргүүлсэн хуурамч бус, жинхэнэ босоо бичиг
- **Хөрвүүлэлт**: Satsrag/mongol-convert 0.7.1 WASM, локалаар ажиллана
- **Нөөц фонт**: Noto Sans Mongolian (SIL OFL 1.1)

## Хэрэгжүүлсэн

### Засвар ба зохиомж
- Босоо баялаг текст: дээр → доош, багана зүүн → баруун; хэвтээ тасралтгүй цаас, томруулах боломжтой
- Гарчиг / үндсэн текст / жагсаалт; тодруулах, налуулах, доогуур зурах, үсгийн өнгө
- Буцаах / дахин хийх, хайх ба бүгдийг солих
- Баримтын түвшний фонт, үсгийн хэмжээ, мөрийн зай, зэрэгцүүлэлт, хуудасны зах, туслах шугам
- Удирдлагын тэмдэгтийн самбар: FVS (U+180B–180D), MVS (U+180E), NNBSP (U+202F), ZWJ / ZWNJ, монгол цэг тэмдэг
- Сонгосон хэсгийн кодын цэгийг шууд харуулах (U+XXXX), тэмдэгт / үг / хувийн мужийн тоо

### macOS-ийн локал боломжууд
- AppKit цэс, натив нээх / хадгалах цонх, хадгалаагүй үед гарахад анхааруулах
- **Системийн бүх фоныг жагсааж**, монгол бичгийн кодын цэгийн хамрах хүрээг шалгана — суусан монгол фоноо шууд сонгох боломжтой
- Системийн гарын оролтын аргын үсэг бүрдүүлэх үе шатанд холбогдож, **үсэг бүрдүүлж байх үед баримтыг өөрчлөхгүй**
- Баримтыг `.mglx` хэлбэрээр хадгална (баялаг текст, фонтын тохиргоо, импортолсон эх байтыг хамт хадгална)
- TXT / HTML экспорт, системийн хэвлэл болон PDF болгон хадгалах

## Гурван кодчиллын профайлын бодит дэмжлэг

Анхны зураг дээрх гурван сонголт нь өөр өөр **глиф ба удирдлагын конвенц**-ыг илэрхийлнэ.
Эдгээр нь Unicode-ийн хувилбарын дугаар биш:

| Профайл | Энэ хувилбарт | Хийгдээгүй |
| --- | --- | --- |
| Монгол бичиг (Улсын стандарт 2023) | Unicode эх бичвэрийг засварлах, FVS / MVS хадгална, сонгосон фоноор хэлбэржинэ | GB/T 25914-2023 бүрэн нийцэл |
| Монгол бичиг (Улсын стандарт 2010) | Хуучин конвенцыг хэвээр хадгална; үсэг, хувилбарын сонголт, дагаврын тусгаарлагчийг дахин бичихгүй | 2010 ↔ 2023 автомат шилжилт |
| Монгол бичиг (Мэнксофт кодчилол) | Хувийн хэрэглээний мужийн эх бичвэрийг засварлах; MenkShape / MenkLetter хөрвүүлэлтийн урьдчилсан харагдац ба хуулбар экспорт | Бүх PUA фонтын зураглал, алдагдалгүй буцах баталгаа |

**Дээд талын профайлыг солих нь зөвхөн баримтын мета өгөгдлийг өөрчилнө, текстийн кодын цэгийг
хэзээ ч дахин бичихгүй.** Энэ нь зориудын шийдэл: автомат шилжилт нягтлагдаагүй, чимээгүй
хөрвүүлэлт текстийг гэмтээнэ.

`Олон улсын 2010` / `Олон улсын 2023` нэршлийн тухайд: эдгээр нь GB/T 25914-2010 ба
GB/T 25914-2023 гэсэн хоёр улсын стандартын глифын конвенц байх магадлалтай (2023 оны хэвлэл
2010 оныг орлосон), Unicode-ийн хувилбар биш. Аль нэг компанийн программын хэрэгжүүлэлтийг
энэ төсөл шалгаагүй.

### GB18030-ийн байр суурь

GB18030 нь **файлын байт кодчиллын түвшин** юм. Энэ нь монгол бичгийн нэрлэсэн тэмдэгт, глифын
конвенц, фонтын хэлбэржилт гэсэн гурваас тусдаа асуудал. Импортлохдоо системийн декодлогчийг
ашиглана, экспортолсон текст үргэлж UTF-8 байна.

## Хөрвүүлэлтийн аюулгүй байдал

Хэмжилтийн үр дүн: одоогийн нээлттэй эхийн хөрвүүлэгчээр `ᠮᠣᠩᠭᠣᠯ` гэсэн жишээ үгийг
хоёр тийш хөрвүүлэхэд **нэрлэсэн үсгүүд ижил болж буцаж ирэхгүй**. Иймд:

- Хөрвүүлэлт нь **зөвхөн урьдчилсан харагдац ба хуулбар үүсгэнэ**, баримтын үндсэн хэсгийг хэзээ ч орлуулахгүй
- Хөрвүүлэлт бүр автоматаар хоёр тийш шалгаж, алдаа гарвал тодорхой анхааруулна
- Хөрвүүлэгч анхааруулга өгөхгүй байх, глиф төстэй харагдах нь текстийг алдагдалгүй гэдгийг батлахгүй

> Монгол бичгийн кодчилолын хөрвүүлэлт нь глифыг хэвийн болгохтой холбоотой зайлшгүй мэдээллийн
> алдагдалтай. **Цорын ганц эх хувилбараа хөрвүүлэлтийн үр дүнгээр хэзээ ч бүү дар.**

## Бүтээх

macOS, Apple Command Line Tools, Node.js 22+ шаардана.

```bash
npm install
npm run build:web        # web/ хавтас үүсгэнэ (gitignore-д орсон)
```

Натив програмын бүтээх скрипт анхдагчаар төслийн эцэг хавтас дахь `outputs/` руу бичнэ:

```bash
mkdir -p ../outputs
npm run build:mac        # arm64 + x86_64 компайл хийж ../outputs/Mori.app багцлана
```

Шалгалт:

```bash
npm test                 # 21 кодчилол ба баримтын бүрэн бүтэн байдлын тест
```

Натив интерфейсийн нэмэлт өөртөө шалгалт (тайлан ба дэлгэцийн зураг гаргана):

```bash
../outputs/Mori.app/Contents/MacOS/Mori \
  --smoke-test tests/native-results.json \
  --snapshot docs/preview.png
```

### v0.2-д нэмэгдсэн

- **Сонголтын түвшний фонт ба хэмжээ** — фонт, хэмжээ нь сонгосон текстийг өөрчилнө; сонголт байхгүй бол баримтын үндсэн утгыг өөрчилнө.
- **Догол мөр ба тэмдэгтийн формат** — H1–H3 гарчиг (⌘0–⌘3), догол мөрийн зай, эхний мөрийн догол, мөрийн зай, дөрвөн зэрэгцүүлэлт, дээд ба доод индекс.
- **Хуудасны тохиргоо ба хуудаслалт** — A4/A3, хэвтээ/босоо, захын зай, зөвхөн уншигдах хуудаслалтын урьдчилсан харагдац, хуудасласан PDF.
- **DOCX импорт ба экспорт** — суусан LibreOffice-ийг **тусдаа процесс**оор дуудна. Холбохгүй, багцлахгүй тул GPL-3.0 үүрэг энэ MIT төсөлд хүрэхгүй. `MORI_SOFFICE`-оор зам зааж болно.

### baosao — суурилуулсан DOCX хөдөлгүүр

DOCX нь хаалттай формат биш: энэ нь хэдэн XML хэсгийг агуулсан ZIP сав. **baosao** тэр багцыг өөрөө бичдэг тул **DOCX экспорт ямар ч гадаад хөрвүүлэгч дуудахгүй, LibreOffice шаардахгүй**.

- `src/baosao/zip.js` — хамааралгүй ZIP бичигч (CRC32-той). `CompressionStream('deflate-raw')` байвал ашиглана, эс бөгөөс STORED
- `src/baosao/ooxml.js` — баримтын загварыг WordprocessingML болгох: догол мөр, гарчиг, тод/налуу/доогуур, өнгө, фонт ба хэмжээ, дээд/доод индекс, зэрэгцүүлэлт, догол, мөрийн зай, жагсаалт, хуудасны хэмжээ ба зах
- `src/baosao/index.js` — арван хэсгийг угсарч **шалгана**

**Монгол бичгийн босоо чиглэл `<w:textDirection w:val="tbLrV"/>`** хэлбэрээр бичигдэнэ. `tbRl` нь хятад-япон-солонгосын босоо чиглэл тул шалгалт түүнийг алдахаас сэргийлнэ.

Экспорт бүрийг эхлээд шалгана — төв лавлах, шаардлагатай хэсгүүд, CRC, XML, босоо чиглэл — **шалгалт даваагүй бол файл бичихгүй**.

> **Шалгагдаагүй**: Microsoft-ын MS-OI29500 баримтад Word хүснэгт дотор `tbLrV`-г 90° эргүүлэлт гэж тайлбарладаг. Файл ECMA-376-д нийцэх боловч **Word дээр хэрхэн харагдахыг бодит Word-оор шалгах шаардлагатай**.

## Мэдэгдэж буй хязгаарлалт

- **Гарын оролтын арга**: стандарт үсэг бүрдүүлэх холболтыг хэрэгжүүлсэн, гэхдээ МэнкСофт болон
  бусад аж ахуйн нэгжийн монгол гарын оролтын аргыг компани, хувилбар тус бүрээр бодит төхөөрөмж
  дээр шалгах шаардлагатай. Windows-ийн гарын оролтын арга нь кодчилолын адаптер нэмснээр
  macOS дээр шууд ажиллахгүй.
- **Word-ын боломж**: хүснэгт, зураг, толгой/хөл хэсэг, хуудасны дугаар, зүүлт, засварын тэмдэглэл, сэтгэгдэл байхгүй; хуудаслалт нь зөвхөн уншигдах урьдчилсан харагдац, хуудсан дотор шууд засвар биш.
- **Хуудаслалт ба PDF**: блок тус бүрийг хэмжиж хуудаслалт хийх ба хуудасласан PDF гаргах нь хэрэгжсэн. Нэг хуудсанд багтахгүй урт догол мөр хуваагдахгүй — тусдаа хуудсанд байрлаж тасрах эрсдэлийг мэдэгдэнэ. PDF-ийн глиф тус бүрийн бүрэн бүтэн байдал шалгагдаагүй хэвээр.
- **Тэмдэгтийн хүрээ**: Тод, Сибо, Манж бичгийн бүрэн хөрвүүлэлт шалгасан хүрээнд ороогүй.
- **Нөөц хуулбар**: зөвхөн хамгийн сүүлийн ажлын талбарыг хадгална
  (`~/Library/Application Support/Mori/draft.mglx`), олон хувилбарын түүх биш.
- **Платформын шалгалт**: зөвхөн Apple Silicon дээр бодитоор шалгасан; Intel ба хуучин macOS шалгагдаагүй.
- **Гарын үсэг**: локал түр зуурын гарын үсэг, **Apple Developer ID гарын үсэг болон нотариат хийгээгүй**,
  өөр Mac дээр анх нээхэд аюулгүй байдлын сануулга гарч болно.

## Хувь нэмэр оруулах

Хэрэв энэ төсөл танд хэрэгтэй бол хамгийн үнэ цэнэтэй хувь нэмэр нь **бодит шалгалтын дээж**
өгөх юм: таны ашигладаг гарын оролтын аргын нэр ба хувилбар, мөн кодчилол тус бүрээс 3–5
нийтэд нээлттэй жижиг дээж. Кодчиллын нийцлийн асуудлыг зөвхөн бодит өгөгдлөөр шийдэж болно.
