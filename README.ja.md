# Mori — モンゴル文字

伝統モンゴル文字のための縦書き文書エディタ（macOS プレビュー版）。

[English](README.md) · [简体中文](README.zh-CN.md) · [Монгол](README.mn.md) · [Русский](README.ru.md) · **日本語** · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md)

伝統モンゴル文字は**上から下へ、列は左から右へ**書かれます。そのため UI は横長です。紙面は横に
広がり、文字は縦に伸びていきます。

![macOS で動作する Mori](docs/preview.png)

> **状態：動作する開発プレビュー版（v0.2.0）。**
> 編集、システムフォント、原文の保持、明示的な符号化変換は動作します。ただし中国のモンゴル文字
> 国家標準に対する**完全な適合性検証は未実施**であり、企業向け入力メソッドの**実機検証も一切
> 行っていません**。完成した Word の代替品として扱わないでください。

## これは何か

完全にオフラインのローカル Mac アプリです。ネットワーク接続なし、文書のアップロードなし、
クラウドサービスなし、商用フォントや入力メソッドの同梱なし。

- **ネイティブシェル**：Swift + AppKit + WKWebView、ユニバーサルバイナリ（Apple Silicon / Intel）
- **エディタ**：ProseMirror、`writing-mode: vertical-lr` — 回転で模擬したものではなく本物の縦書き
- **変換**：Satsrag/mongol-convert 0.7.1 WASM をローカルで実行
- **代替フォント**：Noto Sans Mongolian（SIL OFL 1.1）

## 実装済み

### 編集と組版
- 縦書きリッチテキスト：上 → 下、列は左 → 右。横方向に連続する紙面、ズーム対応
- 見出し／本文／箇条書き、太字・斜体・下線・文字色
- 元に戻す／やり直す、検索とすべて置換
- 文書単位のフォント、文字サイズ、行間、配置、余白、版面ガイド
- 制御文字パレット：FVS（U+180B–180D）、MVS（U+180E）、NNBSP（U+202F）、ZWJ / ZWNJ、モンゴル文字の約物
- 選択範囲のコードポイントをリアルタイム表示（U+XXXX）、文字数・単語数・私用領域の集計

### macOS ネイティブ機能
- AppKit メニューバー、ネイティブの開く／保存パネル、未保存時の終了確認
- **インストール済みの全フォントを列挙**し、モンゴル文字のコードポイント対応を判定。インストール済みのモンゴル文字フォントをそのまま選択できます
- システム入力メソッドの変換ライフサイクルに接続し、**変換中は本文を変更しません**
- `.mglx` として保存（リッチテキスト、フォント設定、インポートした元のバイト列を保持）
- TXT / HTML 書き出し、システム印刷と PDF 保存

## 3 つの符号化プロファイルが実際にできること

スクリーンショットの 3 つの選択肢は、それぞれ異なる**字形と制御文字の慣習**に対応します。
Unicode のバージョン番号ではありません。

| プロファイル | 本バージョンの動作 | 未実装 |
| --- | --- | --- |
| モンゴル文字（国家標準 2023） | Unicode 原文を編集。FVS / MVS を保持し、選択したフォントで字形化 | GB/T 25914-2023 の完全適合 |
| モンゴル文字（国家標準 2010） | 旧慣習の原文をそのまま保持。字母・異体字セレクタ・接尾辞区切りを書き換えません | 2010 ↔ 2023 の自動移行 |
| モンゴル文字（Menksoft 符号化） | 私用領域の原文を編集。MenkShape / MenkLetter の変換プレビューとコピー書き出し | すべての PUA フォント対応表、無損失往復の保証 |

**プロファイルの切り替えは文書メタデータだけを変更し、本文のコードポイントは決して書き換えません。**
これは意図的な設計です。自動移行は未検証であり、暗黙の変換はテキストを破壊します。

`International 2010` / `International 2023` という名称について：これらは Unicode のバージョンでは
なく、GB/T 25914-2010 と GB/T 25914-2023 という 2 版の国家標準の字形慣習を指す可能性が高いです
（2023 年版が 2010 年版を置き換えています）。特定ベンダーの実装方法は本プロジェクトでは検証していません。

### GB18030 の位置づけ

GB18030 は**ファイルのバイト符号化層**です。モンゴル文字の名目文字、字形慣習、フォントの字形化
とは別の層の問題です。インポート時はシステムのデコーダを使用し、書き出すテキストは常に UTF-8 です。

## 変換の安全性

実測結果：現在のオープンソース変換エンジンでサンプル語 `ᠮᠣᠩᠭᠣᠯ` を往復変換すると、**名目字母が
一致しない状態で戻ってきます**。したがって：

- 変換は**プレビューとコピーの生成のみ**を行い、本文を置き換えることは決してありません
- 変換のたびに往復検証を自動実行し、失敗時は明示的に警告します
- エンジンが警告を出さないこと、字形が似ていることは、無損失の証明にはなりません

> モンゴル文字の符号化変換には字形正規化に伴う本質的な情報損失があります。
> **変換結果で唯一の原本を上書きしないでください。**

## ビルド

macOS、Apple Command Line Tools、Node.js 22+ が必要です。

```bash
npm install
npm run build:web        # web/ を生成（gitignore 済み）
```

ネイティブアプリのビルドスクリプトは既定でプロジェクトの親ディレクトリの `outputs/` に出力します：

```bash
mkdir -p ../outputs
npm run build:mac        # arm64 + x86_64 をコンパイルし ../outputs/Mori.app を作成
```

テスト：

```bash
npm test                 # 符号化と文書整合性の 21 項目
```

ネイティブ UI のセルフチェック（任意。レポートとスクリーンショットを出力）：

```bash
../outputs/Mori.app/Contents/MacOS/Mori \
  --smoke-test tests/native-results.json \
  --snapshot docs/preview.png
```

### v0.2 で追加

- **選択範囲単位のフォントとサイズ** — フォントとサイズのコントロールが選択した文字に適用されます。選択がない場合は文書の既定値を変更します。
- **段落と文字の書式** — 見出し H1–H3（⌘0–⌘3）、段落インデント、先頭行インデント、段落の行間、4 種類の配置、上付き・下付き文字。
- **ページ設定とページ分割** — A4/A3、横置き／縦置き、余白プリセット、読み取り専用のページ分割プレビュー、ページ分割された PDF 出力。分割はブロックごとの実測で計算するため、大きな見出しはその分だけ版面を多く使います。
- **DOCX のインポートとエクスポート** — ローカルにインストールされた LibreOffice を**別プロセス**として呼び出します。リンクも同梱もしないため、LibreOffice の GPL-3.0 義務はこの MIT プロジェクトには及びません。`MORI_SOFFICE` で任意のパスを指定できます。

## 既知の制限

- **入力メソッド**：標準的な変換フックは実装済みですが、Menksoft や各種企業向けモンゴル文字入力
  メソッドは、ベンダーとバージョンごとに実機検証が必要です。Windows の入力メソッドは、符号化
  アダプタを追加しても macOS でそのまま動作することはありません。
- **Word 相当の機能**：表、画像、ヘッダー／フッター、ページ番号、脚注、変更履歴、コメントはありません。ページ分割は読み取り専用のプレビューであり、ページ内での直接編集ではありません。
- **ページ分割と PDF**：ブロックごとの実測によるページ分割と、分割された PDF 出力を実装しました。1 ページに収まらない長い段落は分割されず、単独のページになり裁切りの可能性を警告します。PDF の字形単位の再現性は依然として未検証です。
- **文字体系の範囲**：トド文字、シベ文字、満州文字の完全な変換は検証範囲外です。
- **復元コピー**：直近のワークスペースのみを保持します（`~/Library/Application Support/Mori/draft.mglx`）。バージョン履歴ではありません。
- **プラットフォーム検証**：Apple Silicon のみ実機テスト済み。Intel と古い macOS は未検証です。
- **署名**：ローカルの一時署名のみで、**Apple Developer ID 署名と公証は未実施**です。別の Mac で
  初回起動時にセキュリティ警告が表示される場合があります。

## コントリビュート

このプロジェクトが役に立つなら、最も価値のある貢献は**実際のテストデータ**の提供です。お使いの
入力メソッドの名称とバージョン、そして符号化ごとに 3〜5 件の公開可能な小さなサンプルをいただけると
助かります。符号化の互換性問題は実際のデータでしか解決できません。
